# Employee Management System

A modern Employee Management System built with **Laravel 13**, **Vue 3**, **Inertia.js**, and **Tailwind CSS**. This application uses a pure API Token-based Authentication via **Laravel Sanctum** and implements the **Repository and Service Patterns** for a clean, scalable codebase.

---

## 🚀 Features
- **Pure API Token Authentication**: Fully decoupled from traditional session-based SPA authentication.
- **Repository & Service Pattern**: Clean separation of business logic and database queries.
- **Full CRUD Operations**: Create, Read, Update, and Delete employee records.
- **Advanced Filtering**: Exact-match filtering by Job Title, Department, and Status.
- **CSV Export**: Export filtered employee records directly to a CSV file.
- **Modern UI/UX**: Built with Tailwind CSS, featuring custom Toast notifications and beautiful Modals without third-party libraries.

---

## 📋 Prerequisites
Before you begin, ensure you have the following installed on your local machine:
- **PHP** >= 8.2
- **Composer** (PHP dependency manager)
- **Node.js** (v16 or higher) and **npm**
- **SQLite** (Default database)

---

## 🛠️ Installation & Setup

Follow these steps to get the application running locally:

### 1. Clone the Repository
Extract or clone the project directory to your local machine, then open your terminal and navigate to the project root:
```bash
cd employee-management-system-ouji
```

### 2. Install PHP Dependencies
Run the following command to install all required Laravel packages:
```bash
composer install
```

### 3. Install NPM Dependencies
Run the following command to install Vue, Tailwind CSS, and other frontend dependencies:
```bash
npm install
```

### 4. Environment Configuration
Copy the example `.env` file to create your own local configuration:
```bash
cp .env.example .env
```
Generate the Laravel application key:
```bash
php artisan key:generate
```

### 5. Database Setup
This project uses SQLite as the default database for simplicity. Open your `.env` file and update the database connection setting:
```env
DB_CONNECTION=sqlite
# Remove or comment out DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD
```

Then, create the SQLite database file:
```bash
touch database/database.sqlite
```

### 6. Run Migrations & Seeders
Migrate the database tables and populate them with dummy data (including a test user and 100 sample employees):
```bash
php artisan migrate --seed
```

### 7. Start the Application
You will need two terminal windows to run both the backend and frontend servers simultaneously.

**Terminal 1 (Laravel Backend):**
```bash
php artisan serve
```

**Terminal 2 (Vite Frontend):**
```bash
npm run dev
```

## 🏗️ Architecture Highlights
- **API Token Auth**: Login issues a Sanctum Bearer token. This token is saved in the browser's `localStorage` and attached to all subsequent `axios` requests.
- **Service Layer**: (`app/Services/EmployeeService.php`) Handles business logic, including CSV generation.
- **Repository Layer**: (`app/Repositories/EmployeeRepository.php`) Abstracts all Eloquent queries and database interactions.
